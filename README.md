# 离线双语字幕生成器

完全离线的 macOS 原生应用 — 放入视频，自动生成双语字幕。支持 **SRT**（通用）和 **ASS**（带样式）两种格式。

> ⚠️ **首次使用前**：翻译功能使用 macOS 内置翻译框架，请在 **系统设置 → 通用 → 翻译语言** 中确认已下载源语言和目标语言的离线翻译包（如中文和英文）。

## 特性

- ✅ **完全离线** — 语音识别 + 翻译均在本地完成，无需网络
- ✅ **双语字幕** — 中文在上、英文在下（可互换语言）
- ✅ **ASS 样式** — 自定义字体、字号、半透明背景
- ✅ **一键生成** — 拖入视频 → 自动处理 → 字幕保存到「下载」文件夹
- ✅ **隐私保护** — 所有数据在本地处理，不上传云端

## 系统要求

| 条件 | 要求 |
|------|------|
| 芯片 | Apple Silicon（M1 / M2 / M3 / M4） |
| 系统 | macOS 26.0 以上 |
| 存储 | 约 200MB 可用空间（含模型文件） |

## 快速开始

### 1. 安装依赖

```bash
./setup.sh
```

这一步会：
- 编译 `whisper.cpp` 语音识别引擎
- 下载离线模型（默认 base: 约 142MB）

### 2. 编译应用

```bash
./build.sh
```

### 3. 运行

```bash
open build/BilingualSubtitlesOffline.app
```

首次运行时，macOS 可能提示「无法验证开发者」，请在 **系统设置 → 隐私与安全性 → 仍要打开**。

## 使用说明

1. 选择源语言和目标语言（支持中/英/日/韩/法等 14 种语言）
2. 点击「样式」按钮设置字幕字体、大小、背景透明度
3. 拖入视频文件或点击「选择视频文件...」
4. 等待处理完成：
   - 🔍 提取音频 → 语音识别 → 翻译 → 生成字幕
5. 字幕文件自动保存到「下载」文件夹

## 输出格式

### ASS 样式字幕（推荐）
- 中文 42pt / 英文 30pt（基于 SF Pro Display 字体）
- 半透明深色背景，提高可读性
- 中文在上、英文在下，字号可区分
- 需使用支持 ASS 的播放器（IINA、VLC、mpv 等）

### SRT 通用字幕
- 标准格式，所有播放器兼容
- 字体大小由播放器控制

## 技术架构

| 组件 | 技术 | 说明 |
|------|------|------|
| 界面 | **SwiftUI** | 原生 macOS UI |
| 音频提取 | **AVFoundation** | 系统内置 |
| 语音识别 | **whisper.cpp** | 本地推理，CPU 运行 |
| 翻译 | **Apple Translation 框架** | 系统级神经网络翻译，完全离线 |
| 字幕生成 | **Swift** | SRT + ASS 双格式 |
